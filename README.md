## 🚀 Quickstart

```bash
git clone https://github.com/Stiimy/discord-bot.git
cd discord-bot
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt discord.py[voice] yt-dlp PyNaCl
cp .env.example .env  # mets ton token Discord dedans
python3 main.py
```
